Nine TCRs — Full Sequences and Allele Ambiguity

Direct extraction from original 10x files

Summary of findings

This report examines nine TCRs (74, 79, 80, 81, 83, 84, 85, 89, and 90) using their observed, paired TRA and TRB 10x assembled contig sequences. It addresses two questions: (1) what full assembled sequences are available, and (2) which candidate IMGT allele is better supported where the V/J gene annotation is ambiguous.

Key results

  • Sequence extraction: One representative, observed same-cell TRA/TRB pair is selected for each of the nine TCRs using the quality and ranking criteria described in Question 1. These are assembled contigs, not independently validated transduction constructs.
  • Allele comparison: There are 12 ambiguous chain/gene assignments across the nine TCRs. Each is compared with two IMGT candidate alleles (24 contig-to-reference alignments in total).
  • Interpretation: The favored allele is the one matching the observed contig at more allele-discriminating nucleotide positions. Orange highlights indicate nucleotide mismatches; pink indicates alignment gaps.

Question 1. Can you share the full sequences for these nine TCRs?

Answer: Yes. The table below is generated directly from the original 10x assembled contig FASTA. Each of the nine TCRs is represented by one observed same-cell TRA/TRB pair. These are the full available assembled contig sequences, not independently verified complete transduction constructs.

Input files

Answer: This report reads the three original input files directly. It does not require a previously generated sequence CSV.

Original file What it supplies

filtered_contig.fasta Actual assembled nucleotide sequences

Place these three files in the same folder as this QMD and render it. The extraction runs automatically.

How the representative sequences were selected

Answer: For each TCR, we locate its listed TRA and TRB contigs in the original annotation CSV, attach the exact nucleotide strings from the original FASTA, and match sample + barcode to find both chains in the same cell.

Only pairs with is_cell, high_confidence, full_length, and productive true for both chains are eligible. Among eligible pairs, we rank the exact TRA+TRB nucleotide pair by the number of supporting cells, then combined UMIs, then sequence length. We choose an observed pair, never a synthetic consensus.
